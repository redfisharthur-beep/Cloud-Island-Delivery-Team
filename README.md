# Cloud Island Delivery Team

## Cloudflare Pages

1. Create a Pages project and choose **Import an existing Git repository**.
2. Select `redfisharthur-beep/Cloud-Island-Delivery-Team` and use the `main` branch.
3. Choose **None** as the framework preset.
4. Set the build command to `exit 0` and the build output directory to `.`.
5. Deploy. The site serves the root `index.html`.

The game is an HTML5 canvas project with optimized WebP art assets and no package installation or build step. It is designed for landscape mobile play. Tapping the play icon requests fullscreen and landscape orientation where supported. For an app-like fullscreen launch, install it to the home screen; the web app manifest requests fullscreen landscape mode. On phones, a circular joystick sits on the left and the four icon-only skills form a raised, thumb-reachable cluster at the lower right; attack and heal glow when charges are available. Desktop uses A/D to move, W to jump, S to crouch, P to dash, O to use an attack charge, and L to spend a healing charge. A life bar and icon-only inventory/status strip stay visible during play. Each of the three stages ends with a custom illustrated boss. Players can defeat each boss with attack charges or activate three floor sigils in order; later bosses add slow and poison effects. Pickups include wing, shield, star, attack charges, and healing charges; rare pickups rise in a tall light beam. Collectible coins use a beveled, rotating gold design with stage-specific metal accents. Stage-specific carved platforms, moving lifts, wind currents, frame-by-frame courier animations, and smoothly telegraphed enemy lunges round out the routes.
